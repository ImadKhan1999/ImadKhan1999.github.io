Telegram to Drive

A personal utility that saves files sent to a Telegram bot straight into the owner's Google Drive.

Privacy Policy Terms of Service Contact

What it does

Telegram to Drive is a small self-hosted bot. You forward a file, video, photo or document to it on Telegram, and it transfers that file into your own Google Drive account and replies with a link to it.

It exists to move large media out of Telegram and into Drive without downloading it to a computer first.

How it works

  • You send or forward a file to your own Telegram bot.
  • The bot reads the file from Telegram in small pieces held only in memory.
  • Each piece is passed directly to the Google Drive API as it arrives.
  • Nothing is written to the disk of the machine running the bot.
  • The bot replies with the Google Drive link for the finished upload.

Single-user by design

Each installation is operated by one person, uses that person's own Google account, and is restricted to a list of approved Telegram user IDs. There is no shared service, no public sign-up and no hosted version.

Google Drive access

The application requests a single Google OAuth scope, .../auth/drive.file. That scope grants access only to files the application itself creates. It cannot open, read, modify or delete anything else in the connected Drive account.

Uploads are placed in a folder the application creates, named Telegram Uploads by default.
