1. Who this covers

Telegram to Drive ("the application") is a self-hosted personal tool. Each installation is run by an individual on their own machine, connected to their own Google account and their own Telegram bot. There is no central server operated by the author, and no hosted service that other people sign up for.

This policy describes what the application does with data when you run it and connect it to your Google account.

2. What the application accesses

The application handles only the following:

  • Files you deliberately send it. Any file, video, photo, audio or document you send or forward to your own Telegram bot.
  • Your Google Drive, limited to files it creates. Through the OAuth scope https://www.googleapis.com/auth/drive.file.
  • Your Telegram user ID. Used only to check that you are on the approved list of users for your installation.
  • Google Drive storage totals. Read when you use the status command, to show how much space is left.

3. Scope of Google account access

The application requests exactly one Google OAuth scope, .../auth/drive.file. Google restricts this scope to files the application itself created. The application therefore cannot read, list, modify, download or delete any pre-existing file or folder in your Drive.

It does not request access to Gmail, Contacts, Calendar, Photos or any other Google service.

4. Google user data and Limited Use

The use by this application of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically, Google user data obtained through this application is:

  • used only to provide the upload feature you requested;
  • never transferred to any third party, except as required to provide that feature or to comply with law;
  • never used for advertising, marketing, profiling or any form of resale;
  • never read by a human, except with your explicit consent, for security purposes, or where required by law.

5. Where data goes and how long it is kept

  • File contents are not stored. Bytes travel from Telegram, through the memory of the machine running the application, and into Google Drive. Nothing is written to the disk of that machine, and each portion is discarded as soon as it has been passed on.
  • Uploaded files live in your Drive. Once an upload finishes, the file belongs to your Google account and is governed by the terms of Google. You can move or delete it at any time.
  • Credentials stay local. Your Google refresh token, Telegram bot token and session file are stored only on the machine you run the application on. They are never transmitted anywhere except to Google and Telegram to authenticate.
  • Logs. A local log records file names, sizes and timestamps so you can troubleshoot. It contains no file contents and no credentials, and it never leaves your machine.

6. Sharing

The author of the application receives no data whatsoever. Nothing is sold, rented, traded, or handed to advertisers, analytics providers or data brokers. The only parties involved in an upload are Telegram, your machine, and Google.

If you enable the optional "anyone with the link" setting, uploads are given a public Google Drive link. That is a choice you make in your own configuration; when it is turned off, uploads stay private to your Google account.

7. Security

Traffic to Telegram and to Google is encrypted in transit. Because the application runs on hardware you control, the security of the stored credentials depends on the security of that machine. Keep your token and configuration files private, and do not run the application on a machine other people can access.

8. Withdrawing access

You can disconnect the application from your Google account at any time at myaccount.google.com/permissions. Revoking access immediately stops all further uploads. Files already uploaded remain in your Drive; delete them there if you no longer want them.

Deleting the local credential files removes the stored authorisation from your machine.

9. Children

The application is not directed at children and is not intended for use by anyone under 13.
